# v2.12.4 — Стабильность очереди результатов, безопасный CWD Windows, поддержка эмодзи PowerShell и чистота чата

Патч-релиз **v2.12.4** устраняет критические проблемы при работе AI-агентов в чатах (ChatGPT, Claude, DeepSeek, Arena), исправляет дефекты очереди команд, устраняет падения относительных путей в Windows и обеспечивает полную поддержку UTF-8 эмодзи в консоли.

---

## 🛠 Ключевые исправления и улучшения

### 1. 🔴 Устранение залипания и дублирования очереди результатов
- **Реестр сессионных выполнений (`AX.sessionExecuted`)**: при реактивном перерендере ленты чата движками веб-приложений старые блоки кода из истории диалога больше **никогда не перезапускаются автопилотом повторно**. Повторный запуск возможен только осознанным ручным нажатием кнопки ▶ пользователем.
- **Чистота диалога**: убран спам сообщениями `noteToChat` при пропуске команд (`status=skipped`). Статусы `already-executed`, `duplicate`, `loop-guard` теперь отображаются только локально на панели, не загрязняя поле ввода чата.
- **Защита от двойной вставки**: в `AX.insertIntoChat` встроена проверка дубликатов — идентичный результат не вставляется дважды. Временный маркер `[LOCAL EXEC] seq=N status=running` корректно замещается итоговым результатом `[LOCAL EXEC RESULT]`.
- **Корректный порядок нескольких блоков в одном сообщении**: если в одном ответе ИИ содержится несколько блоков кода, `autoSend` дожидается завершения всей очереди, последовательно наполняя поле ввода, и только затем отправляет суммарный результат модели.

### 2. 🔴 Безопасный CWD по умолчанию (фикс `C:\Windows\System32`)
- В `server/server.py` добавлена функция `_get_safe_cwd()`.
- Если сервер запущен через ярлык, системную службу или автозапуск Windows, где текущий каталог — `C:\Windows\System32`, сервер автоматически переключает рабочую папку на домашний каталог пользователя (`%USERPROFILE%` / `~`).
- Относительные пути к файлам проектов (`fps.cpp`, сборка, тесты) теперь работают стабильно без требования писать полные пути.

### 3. 🟡 Полная поддержка UTF-8 и эмодзи в PowerShell (⚡ ✅ 🎯)
- В эвристике `_readable_score` и `_decode_one_line` добавлены диапазоны символов Emoji и Unicode (`0x2600..0x27BF`, `0x1F300..0x1F9FF`). Валидный UTF-8 вывод с эмодзи больше не перетирается ошибочным декодером cp866.
- В скрипты PowerShell добавлен явный вывод в UTF-8 без BOM: `[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)`.

### 4. 🟡 Понятная диагностика ошибок .NET / PowerShell
- В анализатор `FAILURE_RULES` добавлен перехват .NET-исключений (`FileNotFoundException`, `DirectoryNotFoundException`, `Could not find file`). Вместо многострочного стектрейса пользователь и ИИ видят лаконичное и точное объяснение: *«Путь или файл не найден»* с рекомендацией проверить `cwd`.

### 5. 🏷 Синхронизация брендинга и чистота интерфейса
- Версия сервера в заголовках обновлена на `TerminalBridge/2.12.4`.
- Файл стабильного токена перенесён в `~/.terminal-bridge.token` с поддержкой бесшовной миграции.
- Имена экспорта настроек и журнала приведены к `terminal-bridge-settings.json` и `terminal-bridge-journal.md`.
- В меню Popup устранена выдача сырого JSON-дампа в статусе сервера — теперь отображается лаконичный статус `✅ Сервер v2.12.4 на связи (порт 8765)`.
