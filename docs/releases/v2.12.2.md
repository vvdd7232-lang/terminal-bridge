# v2.12.2 — Кросс-сайтовая совместимость, Shadow DOM и диагностика Git

Релиз, направленный на повышение надёжности и бесшовную работу расширения на всех поддерживаемых платформах веб-чатов с искусственным интеллектом (ChatGPT, Claude, DeepSeek, Gemini, Arena, Grok, Perplexity, GigaChat, Qwen, Mistral, AI Studio), а также на улучшение диагностики сбоев в окружении Git.

## 1. Расширенная поддержка полей ввода чатов (`AX.CHAT_INPUT_TIERS`)

- **Gemini**: добавлена поддержка современных Quill и contenteditable-контейнеров (`rich-textarea [contenteditable]`, `div.ql-editor`).
- **Алиса / Яндекс**: добавлены селекторы для динамических классов `[class*="AliceInput" i]`.
- **Grok**: внедрено распознавание как `textarea`, так и `div[contenteditable="true"][aria-label*="Grok" i]`.
- **Perplexity**: селекторы поисковых композеров `textarea[data-testid*="search" i]`.
- **GigaChat, Qwen, Mistral, Google AI Studio, Arena / LMSYS**: специализированные и универсальные селекторы блоков ввода.
- **Безопасная вставка в React/Vue (`setTextareaReactSafe`)**: поддержаны как `HTMLTextAreaElement`, так и `HTMLInputElement` со сквозным диспатчем событий `input` и `change`.
- **Надёжная вставка в Rich Text / ProseMirror (`insertIntoChat`)**: добавлен контроль границ выделения (`Selection` / `Range`) и фоллбэк на `beforeinput` при блокировках стандартного `execCommand`.

## 2. Поддержка Shadow DOM и поиск кнопок отправки

- **Shadow DOM**: сканирование кода (`<pre>`) в `content.js` теперь проходит по вложенным Shadow Root деревьям изолированных веб-компонентов.
- **Кнопка отправки (`findSendButton`)**:
  - Обход дерева форм, родительских композеров и активных Shadow Root.
  - Поддержка локализованных меток на русском языке (`[aria-label*="отправить" i]`, `[title*="отправить" i]`).
  - Проверка атрибута `aria-disabled !== 'true'` и повторные попытки с интервалом до 2.5 с для реактивного обновления состояния кнопки в React-интерфейсах.

## 3. Чтение кода в фоновых вкладках (`domText`)

- В браузерах Chromium и Firefox свойство `innerText` в неактивных (свёрнутых или фоновых) вкладках возвращает пустую строку, так как макет страницы не отрисовывается.
- Добавлен вспомогательный метод `domText(el)` с гарантированным фоллбэком на `textContent`. Теперь команды распознаются, проверяются и исполняются автопилотом без сбоев даже при работе вкладки в фоновом режиме.

## 4. Контроль активной генерации ИИ (`waitForSettle` & `isGenerationActive`)

- Функция ожидания стабилизации ответа ИИ теперь проверяет статус стриминга (`isGenerationActive`).
- Автопилот не стартует преждевременно, пока ИИ продолжает генерацию текста и горит кнопка остановки (Stop / Остановить / `.result-streaming`).

## 5. Диагностика ошибок Git (`describeFailure`)

- Добавлены новые правила анализа ошибок в `FAILURE_RULES`:
  - `git-not-repo`: распознаёт `fatal: not a git repository` и подсказывает перейти в каталог репозитория (`cd <папка> && git ...`) либо настроить рабочую папку в опциях (⚙️).
  - `git-auth`: распознаёт отказ авторизации или запросы учётных данных в неинтерактивном режиме.

## Тестирование

- Добавлены тесты Git-ошибок в `tests/failure-explain.test.js`.
- Все 10 сьютов JavaScript-тестов (`npm test`) и 138 unit-тестов Python сервера (`test_server.py`, `test_mcp_client.py`) успешно пройдены.
