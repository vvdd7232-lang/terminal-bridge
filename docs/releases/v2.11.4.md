# v2.11.4 — Алиса и GigaChat

Патч-релиз: расширение теперь работает на двух новых сайтах — Алисе (alice.yandex.ru) и GigaChat (giga.chat).

## Поддержка сайтов: Алиса и GigaChat

- **Манифесты.** В `manifest.json` и `manifest.chrome.json` добавлены домены `*://alice.yandex.ru/*`, `*://*.alice.yandex.ru/*`, `*://giga.chat/*`, `*://*.giga.chat/*` в обе секции — `content_scripts` (иначе контент-скрипт не запускается на сайте) и `web_accessible_resources` (для вставки картинок из команды `view`).
- **Поле ввода Алисы.** В `ax-core.js` добавлен селектор `textarea.AliceInput-Textarea` — так называется поле ввода Алисы (проверено по живому HTML сайта).
- **GigaChat.** Поле ввода находится общими селекторами (`textarea[placeholder]`, `contenteditable`, `textarea`): в бандле GigaChat используется rich-text редактор на contenteditable. Если поле не найдётся — F12 → `__axDiag()` на giga.chat, добавлю точный класс.
- **Прочее.** Контент-скрипт ищет `execute`-блоки по `<pre>` — работает на любом сайте без отдельной логики.
