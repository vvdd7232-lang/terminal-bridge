# v2.12.0 — UX Agent Mode: Прерывание процессов, Virtualenv и Умное исправление

Большое обновление UX для работы в режиме AI-агента: прерывание зависших команд, автоматическая работа в виртуальных окружениях Python и 1-клик исправление ошибок через ИИ.

## 1. Прерывание выполнения команд (Command Abort)

- **Кнопка `⏹ Прервать`.** Во время выполнения команды кнопка запуска превращается в заметную кнопку остановки (`.ax-btn-abort`) с мягкой пульсацией. Больше нет необходимости ждать бесконечного таймаута или перезапускать сервер вручную.
- **Дерево процессов.** На бэкенде `server.py` реализован эндпоинт `POST /abort` с поддержкой `run_id`. Процессы запускаются в изолированных группах (`start_new_session=True` на POSIX, `CREATE_NEW_PROCESS_GROUP` на Windows). При отмене дерево процессов гарантированно завершается через `os.killpg(SIGKILL)` / `taskkill /F /T /PID`.
- **Код возврата 130.** Прерванный процесс корректно возвращает стандартный POSIX код завершения `exit=130` с флагом `aborted: True`, а панель расширения информирует: `⏹ Команда прервана пользователем (exit=130)`.

## 2. Автоматическое обнаружение Virtualenv

- **Авто-поиск окружений.** Функция `_detect_venv_python(cwd)` проверяет наличие виртуальных окружений (`.venv`, `venv`, `env`, `.env`) в текущей рабочей директории и родительских каталогах до двух уровней вверх.
- **Кроссплатформенность.** Поддерживает `bin/python` на Linux/macOS и `Scripts/python.exe` на Windows с проверкой прав на выполнение. При отсутствии виртуального окружения происходит безопасный фоллбэк на системный `sys.executable`.
- **Бейдж виртуального окружения.** При выполнении в виртуальном окружении в панели отображается компактный индикатор `🐍 .venv` с полным путём в подсказке.

## 3. Умное исправление ошибок («✨ Как исправить»)

- **1-клик генерация промпта.** При возникновении ошибки выполнения рядом с кнопкой «В чат» появляется акцентная кнопка `✨ Как исправить`.
- **Контекстный анализ.** Функция `AX.formatFixPrompt(cmd, runner, result)` анализирует причину сбоя через `AXDetector.describeFailure`, извлекает компактный хвост stderr и формирует структурированный запрос к нейросети с просьбой объяснить причину и сгенерировать исправленный блок `execute`.
- **Вставка в поле ввода.** Запрос автоматически вставляется в активное поле чата и копируется в буфер обмена.
