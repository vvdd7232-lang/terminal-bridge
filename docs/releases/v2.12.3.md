# v2.12.3 — 3 Премиальных стиля оформления, полное визуальное обновление и галерея скриншотов

Релиз **v2.12.3** представляет масштабный редизайн интерфейса с поддержкой **трёх уникальных стилей оформления** на выбор, переключаемых в один клик прямо из всплывающего меню расширения (Popup) или со страницы настроек:

---

## 🎨 3 Премиальных стиля оформления на выбор

1. **⚡ Linear / Vercel (Тёмный минимализм)**:
   - Глубокий тёмный карбоновый фон (`#090a0f`), ультратонкие границы 1px (`rgba(255, 255, 255, 0.08)`).
   - Моноширинные компактные микро-бейджи и неоновые акценты.
   - Минималистичная кнопка запуска с деликатным внутренним свечением.

2. **💻 Warp / Cursor (Терминал разработчика)**:
   - Эстетика современной рабочей станции с элементами окна терминала.
   - Цветные индикаторы macOS (`● ● ●` красный, желтый, зеленый) в шапке панели.
   - Фирменный консольный шеврон командной строки (`$`) перед текстом команды.
   - Глубокий терминальный CRT-фон с внутренней подсветкой.

3. **🔮 Raycast / macOS Glass (Матовое стекло)**:
   - Парящие полупрозрачные карточки с эффектом `backdrop-filter: blur(24px) saturate(180%)`.
   - Мягкие объемные градиенты, люминесцентные ореолы и плавные скругленные формы (pill).
   - Светящиеся при наведении акцентные кнопки.

---

## 📱 Быстрое меню расширения (Popup)

- **Интегрированный переключатель стилей (`Linear` · `Warp` · `Glass`)** — мгновенное переключение визуала без перезагрузки страницы.
- **Индикатор статуса сервера**: живая пульсация точки соединения (`ax-pulse`) и цветные полупрозрачные плашки.
- **Интерактивные переключатели**: тактильные свитчи с плавными переходами и неоновой индикацией активности.
- **Градиентный бренд-значок**: мягкое свечение и изящный бейдж `by Marusya`.

## 🛠 Исправление вёрстки и стабильность

- **Защита от сжатия кнопок**: на панель выполнения и вложенные элементы добавлен принудительный сброс блочной модели (`box-sizing: border-box !important`, `flex-shrink: 0`), предотвращающий искажения на ChatGPT, Claude, DeepSeek, Arena.
- **Очистка устаревших панелей**: автоматическое удаление осиротевших панелей при реактивной перерисовке списка сообщений.
- **Безопасная зона**: индикатор `#ax-server-dot` и уведомления `.ax-toast` вынесены выше по оси Z над областью ввода чата.
