## Как выпустить релиз

1. Поднять версию в `extension/manifest.json` (единственный источник правды)
   и синхронно в `manifest.chrome.json`, `server/server.py`, `server/mcp_client.py`.
2. Добавить `docs/releases/vX.Y.Z.md` с заголовком вида «vX.Y.Z — короткое описание».
3. `python3 tools/check_versions.py` — должно быть без проблем.
4. `python3 tools/build_release.py` — соберёт `dist/` и обновит `firefox-addon.xpi`.
5. `python3 tools/publish_release.py` — создаст тег, релиз и загрузит ассеты.
