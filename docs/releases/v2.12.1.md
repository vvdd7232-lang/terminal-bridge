# v2.12.1 — Стабилизация автопилота: очереди, отмена модалок и синхронизация настроек

Патч-релиз, устраняющий критические пограничные состояния в подсистеме автопилота («автопилот» / `autoExecute`), предотвращающий гонки при выполнении очереди и зависание отменённых диалогов.

## 1. Устранение зомби-состояния при отмене модалки (`confirmModal`)

- **Проблема:** Если при подтверждении опасной команды или вызова MCP пользователь нажимал «Отмена» либо кликал в фоновую область, выполнение прерывалось без сброса статуса панели. Панель оставалась с классом `ax-running` и надписью `🤖 Автопилот: выполняется…`, а кнопка «Отмена авто» зависала в шапке.
- **Решение:** В обработчик отмены добавлен гарантированный вызов `stopAutoTimer()`, очистка статуса (`Действие отменено пользователем — нажмите ▶ для запуска`), удаление кнопки отмены авто и вызов `autoHandle.finish()`.

## 2. Устранение состояния гонки (Race Condition) при ручном запуске очереди

- **Проблема:** Если пользователь нажимал `▶ Выполнить` на блоке, стоящем в очереди автопилота (`AX.autoQueue`), удаление из очереди откладывалось до завершения исполнения. При завершении предыдущего активного блока планировщик `AX.pumpAutoQueue()` видел ожидающую панель всё ещё в очереди и запускал её повторно и параллельно.
- **Решение:** В обработчике `btnRun.onclick` вызов `dequeueAuto(autoHandle)` теперь выполняется немедленно перед запуском команды.

## 3. Мгновенная остановка автопилота при отключении в настройках

- **Проблема:** При отключении флажка `autoExecute` в настройках или попапе расширения активные таймеры обратного отсчёта продолжали тикать и отправлять команды без подтверждения пользователя.
- **Решение:** Реализована функция `AX.cancelAllAuto(msg)` и метод `autoHandle.cancel(msg)`. Слушатель изменений `chrome.storage.sync.onChanged` в `content.js` при переходе `autoExecute` в `false` немедленно останавливает все тикающие таймеры и очищает очередь автопилота.

## 4. Корректная финализация при ранних пропусках (`runAutoNow`)

- **Проблема:** При ранних пропусках (пустая команда, `isHardDangerous`, дубликат `dupAge`, `historyAge`, `loop-guard`, лимит на вкладку) флаг `done` не выставлялся, из-за чего блок мог повторно ошибочно активироваться через `applyPendingAuto()`.
- **Решение:** Во всех ветках пропуска теперь вызываются `stopAutoTimer(...)` и `autoHandle.finish()`.

## 5. Корректный перезапуск и кнопка быстрого включения автопилота

- В `autoHandle.retry()` очередь очищается корректно как для завершённых, так и для ещё не стартовавших панелей без сброса чужого флага `AX.autoActive`.
- Кнопка «Включить авто» (`.ax-btn-quickauto`) теперь использует централизованный `autoHandle.retry()`.
